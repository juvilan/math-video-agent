# /storyboard

주제: **$ARGUMENTS**

`math-storyboard` 스킬을 따라 기획 문서만 만든다. 코드는 쓰지 않는다.

1. 핵심 한 문장을 확정한다. 한 문장으로 안 써지면 주제를 쪼갠다.
2. 5단 비트 구조(훅 / 직관 / 형식화 / 확장 / 여운)로 배치한다.
   **그림이 기호보다 먼저 온다.**
3. 비트마다 내레이션을 **실제 문장으로** 쓰고 길이를 계산한다
   (한국어 글자 수 ÷ 5.5 ≈ 초).
4. 각 비트에 Scene 이름과 시작 템플릿을 지정한다.
5. `skills/math-storyboard/templates/storyboard.md` 형식으로 출력하고
   파일로 저장한다.
6. 마지막에 검토 체크리스트를 실제로 대조해서 결과를 적는다.

대상 시청자가 불명확하면 **그것만** 한 번 묻는다. 나머지는
기본값으로 진행하고 가정을 명시한다.
