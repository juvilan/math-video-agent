# 효과음과 음악

Manim은 렌더할 때 오디오를 영상에 직접 먹싱한다. 편집 툴로
넘기기 전에 소리를 붙일 수 있다.

**소리는 렌더 결과를 봐도 보이지 않는다.** 이 문서의 함정 세 개는
전부 "에러 없이 소리만 사라지는" 종류다. 반드시 `qc.py stats`로
오디오 트랙을 확인한다.

---

## 1. 파일 두기

```
프로젝트/
  assets/sfx/
    generate.sh    이 팩을 만든 스크립트 (톤을 고치려면 여기)
    *.wav
  scenes/
```

레포에 딸려오는 팩 (전부 ffmpeg 합성 — 저작권 무관, 피크 −3dBFS):

| 파일 | 길이 | 쓰는 순간 |
|---|---|---|
| `pop` | 0.16s | 객체 하나가 화면에 놓일 때 |
| `tick` | 0.05s | 점 찍기·라벨 붙이기 같은 작은 표시 |
| `click` | 0.09s | 단계 전환 (tick 보다 낮고 둔탁) |
| `whoosh` | 0.42s | 이동·변형 |
| `sweep` | 0.90s | 씬이 통째로 바뀌는 큰 전환 |
| `rise` | 0.55s | 누적·수렴 (리만합을 잘게 쪼갤 때) |
| `drop` | 0.55s | 감소·소멸 |
| `reveal` | 0.55s | 결과 공개 (두 음이 올라감) |
| `chime` | 1.30s | 결론 확정. 영상당 한두 번 |

톤이 안 맞으면 `generate.sh` 의 수식을 고쳐 다시 돌린다. 주파수를
`(f0 + k*t)` 로 쓰면 피치가 쓸리고, `exp(-a*t)` 를 곱하면 감쇠한다.

```bash
bash assets/sfx/generate.sh     # 길이·피크·RMS 표까지 찍어준다
```

`MV_SFX_DIR` 로 위치를 바꿀 수 있다 (기본 `assets/sfx`).

포맷은 wav / mp3 / ogg / flac / m4a / aiff. **wav를 권한다** —
mp3는 앞에 무음 패딩이 붙어 타이밍이 밀린다.

## 2. 쓰기

`scene_base.MathScene` 을 상속하면 `self.sfx()` 가 있다.

```python
class Intro(MathScene):
    def construct(self):
        self.sfx("whoosh", gain=-12)          # 확장자 생략 가능
        self.play(Create(circle), run_time=1.5)

        self.sfx("pop")                       # gain 기본 -8dB
        self.play(FadeIn(label))
```

| 인자 | 뜻 |
|---|---|
| `name` | `assets/sfx/` 안의 파일명(확장자 생략 가능) 또는 전체 경로 |
| `gain` | dB. 기본 `-8`. 효과음은 내레이션보다 확실히 낮아야 한다 |
| `ahead` | 앞당길 초. 기본 `0.06` — 소리가 화면보다 살짝 먼저 나야 붙어 들린다 |

**소리는 `play` 앞에 놓는다.** `add_sound`는 "지금 시점"에 소리를
예약하므로, `play` 뒤에 쓰면 애니메이션이 끝난 뒤에 난다.

원시 API를 직접 쓸 수도 있다:

```python
self.add_sound("assets/sfx/pop.wav", gain=-8, time_offset=-0.06)
```

`self.sfx()` 는 여기에 **파일 없음 경고**와 **음수 타임스탬프
방지**를 얹은 것뿐이다.

## 3. 함정 세 개 (전부 조용히 실패한다)

### ① 캐시가 켜져 있으면 소리가 통째로 빠진다

manim은 캐시된 애니메이션을 `skip_animations=True` 로 돌리고,
`Scene.add_sound` 는 그 플래그를 보면 **아무 일도 안 하고 return**
한다. 결과는 에러 없이 소리만 없는 영상.

```bash
manim -qh --disable_caching scene.py MyScene    # 반드시
```

`mv.py` 는 소스에 `add_sound(` 나 `.sfx(` 가 있으면 캐시를
자동으로 끈다. 직접 `manim` 을 칠 때는 잊지 말 것.

### ② 씬 맨 앞에서 앞당기면 예외가 나고, 그 예외가 삼켜진다

`time_offset` 이 음수라 타임스탬프가 0 미만이 되면 manim 이
`ValueError: Adding sound at timestamp < 0` 을 던진다. 그런데
렌더러가 그걸 잡아서 traceback만 찍고 **렌더는 성공으로 끝난다.**

`self.sfx()` 는 현재 씬 시각을 보고 `ahead` 를 잘라내 이걸 막는다.

### ③ 이어붙이면 소리가 사라진다

`ffmpeg -f concat -c copy` 로 씬을 붙일 때, **첫 파일에 오디오
트랙이 없으면 뒤 파일들의 소리가 전부 버려진다.** 경고도 없다.
오디오가 영상보다 짧아도 뒤 씬이 밀린다.

```bash
python3 mv.py join out.mp4 Hook.mp4 Rings.mp4 Unroll.mp4 Result.mp4
```

`join` 은 붙이기 전에 모든 입력에 오디오 트랙을 만들고(무음이라도)
길이를 영상에 맞춘다. 손으로 `concat` 하지 않는다.

## 4. 확인

```bash
python3 qc.py stats out.mp4
```

```
오디오    aac 2ch 44100Hz, 64.01s
```

- **`오디오 없음`** 이 뜨면 소리를 넣었는데 안 붙은 것이다 (위 함정 ①②)
- 오디오 길이가 영상보다 0.5초 이상 짧으면 경고한다 → `join` 을 쓴다

## 5. 어디에 넣나

과하면 유치해진다. 3Blue1Brown 영상에 효과음이 거의 없는 데는
이유가 있다 — **소리는 시선을 끌지만, 수학 영상에서 시선은 이미
화면에 있어야 한다.**

넣을 만한 자리:

| 순간 | 소리 | gain |
|---|---|---|
| 핵심 객체가 처음 등장 | `pop` | -12 |
| 이동·변형 | `whoosh` | -13 |
| 씬이 통째로 바뀌는 큰 전환 | `sweep` | -13 |
| 값이 쌓이거나 수렴 | `rise` | -14 |
| 작은 표시 (점, 라벨) | `tick` | -16 |
| 단계 전환 | `click` | -16 |
| 질문·결과를 던질 때 | `reveal` | -13 |
| 결론이 확정될 때 | `chime` | -12, 한 번만 |

넣지 말아야 할 자리: 자막이 바뀔 때마다, 매 `play` 마다,
카메라가 움직일 때.

**한 씬에 3개를 넘기지 않는다.**

### 음량

| 용도 | gain |
|---|---|
| 강조 효과음 | -8 ~ -10 dB |
| 보조 효과음 | -12 ~ -16 dB |
| 배경음악 | -22 ~ -28 dB |

내레이션을 나중에 얹을 거라면 효과음을 더 낮춘다. 녹음본이
없는 상태에서 맞춰놓은 음량은 목소리가 들어오면 거의 항상 크다.

---

## 6. 배경음악

한 씬에 길게 깔 수는 있지만 **권하지 않는다.** 씬 단위로 잘려
있어서 이어붙이면 음악도 끊긴다.

```python
self.add_sound("assets/music/bed.mp3", gain=-25)   # 씬 시작에 한 번
```

배경음악은 편집 툴(Final Cut / Premiere / DaVinci)에서 완성본
전체에 한 번 까는 게 맞다. Manim은 **씬에 붙는 효과음**까지만
담당한다.

## 7. 저작권

- 직접 만들었거나 라이선스를 확보한 음원만 쓴다
- CC0 / 퍼블릭 도메인이라도 **출처를 레포에 적어둔다**
- 유튜브는 음원 저작권을 자동 검출한다. "어디선가 받은" 효과음은
  수익화가 막히거나 영상이 차단될 수 있다
- 이 레포의 `assets/sfx/*.wav` 는 `generate.sh` 로 합성한 것이다
  (사인 스윕 + 핑크/브라운 노이즈). 순수 합성이라 저작권 문제가
  없고, 그대로 써도 되고 갈아끼워도 된다

### 발소리·폴리 라이브러리를 갖고 있다면

수학 영상에는 거의 안 맞는다. 발소리·문 여닫이·자연음 같은 폴리는
**공간과 물체가 있는 화면**을 전제로 만들어진 소리다. 도형과 수식만
있는 화면에 얹으면 "왜 여기서 이 소리가 나지"가 된다.

굳이 쓴다면 원래 소리로 쓰지 말고 재료로만 쓴다 — 한 발자국만 잘라
피치를 올리면 `tick` 이 되고, 미끄러지는 소리(scuff/slide)를 늘려
필터를 걸면 `whoosh` 계열이 된다. 다만 손이 많이 가고, 위 합성
팩보다 나아진다는 보장이 없다.
