# /storyboard

주제: **$ARGUMENTS**

`math-storyboard` 스킬을 따라 기획 문서만 만든다. 코드는 쓰지 않는다.

**혼자 완성해서 들이밀지 않는다.** 여섯 단계로 나누고 각 단계
끝에서 멈춰 확인받는다.

```
0. 재료 받기      — 이미지/자료가 있으면 LaTeX로 받아쓴다
1. 핵심 한 문장   — 각도가 다른 후보 2~3개를 내고 고르게 한다 ← 게이트
2. 대상·길이·톤   — 한 번에 묶어 묻는다. 대상만은 꼭 확인      ← 게이트
3. 비트 뼈대      — 제목만. 순서가 맞는지만 본다               ← 게이트
4. 콘티           — 비트마다 화면 스케치 + 색 + 씬/템플릿      ← 게이트
5. 내레이션       — 실제 읽을 문장 + 길이 계산                 ← 게이트
6. 확정           — templates/storyboard.md 형식으로 저장
```

게이트에서는 `AskUserQuestion`으로 **후보를 제시**한다. 빈칸을
내밀고 채워달라고 하지 않는다.

사용자가 "알아서 해줘"라고 하면 기본값으로 진행하되, 각 게이트에서
결과를 보여주고 넘어간다. 조용히 6단계까지 가지 않는다.

`--빠르게`를 주면 1~5단계를 한 번에 초안으로 내되, **어느 단계부터
다시 갈 수 있는지 명시**한다.

6단계에서 체크리스트를 실제로 대조해 결과를 적는다. 비트별 목표
길이는 반드시 남긴다 — 렌더 후 `math-video-qc`가 이걸로 실제와
대조한다.
