# 의도 카드 — 원의 넓이 예제

> 이 예제 프로젝트의 취향 기록. 실제 프로젝트에서는 영상마다
> 갱신하며 쌓아간다.

## 1. 정체성

- **채널/시리즈**: 중·고등 수학 개념 시각화
- **주 시청자**: 중1~중2. 공식은 외웠지만 왜 그런지는 모름
- **한 편의 목적**: 이해시킨다

## 2. 톤

| 축 | 선택 |
|---|---|
| 차분함 ↔ 경쾌함 | 차분 2 / 5 |
| 설명 ↔ 발견 | 발견 4 / 5 |
| 엄밀 ↔ 직관 | 직관 5 / 5 |
| 말수 | 적게 — 화면이 말하게 |

## 3. 화면

- **밀도**: 여백 많이
- **한 화면 최대 요소 수**: 3
- **수식 노출**: 최소 — 그림이 끝난 뒤에만 기호를 붙인다
- **색 성향**: 파랑→청록 그라데이션 본체, 노랑 강조, 청록 결론
- **배경**: `#0f0f14`

```
MV_TEXT_SCALE=1.0
```

## 4. 속도

- **기본 배속**: `MV_PACE=1.0`
  (내레이션을 얹을 때는 1.15~1.25 로 올릴 것 — 지금은 자막만이라
   기획보다 22% 짧게 나왔다)
- **한 비트 길이**: 12~25초
- **영상 총 길이**: 1~2분

## 5. 자막

- **표시**: 핵심 구절만
- **한 줄 최대**: 22자
- **위치**: 하단 고정 (buff 0.6 — 0.45 는 title-safe 에 걸린다)

## 6. 효과음

- **정도**: 씬당 2~3개
- **쓰는 순간**: 누적은 `rise`, 큰 변형은 `sweep`, 결론은 `chime` 한 번

## 7. 하지 말 것

```
- 캐릭터·이모지 금지
- 정의부터 시작하지 않기 — 그림이 먼저
- 한 화면에 수식 3개 이상 금지
- 자막에 내레이션 전문 깔지 않기
- 5초 넘게 아무것도 안 움직이는 구간 금지 (결론 읽는 시간은 예외)
```

## 8. 참고
