# 수학 영상 스토리보드

**코드보다 먼저 온다.** 기획 없이 만든 애니메이션은 예쁘지만
아무것도 가르치지 못한다.

산출물은 `templates/storyboard.md` 형식의 문서 하나. 이걸
`manim-video` 스킬이 받아서 씬 코드로 옮긴다.

---

## 1. 먼저 물어볼 것

사용자가 "○○ 영상 만들어줘"라고만 했다면, 코드로 뛰기 전에
아래 중 **답이 없으면 결과가 달라지는 것만** 확인한다.

| 항목 | 기본값 (안 물어봐도 되는 경우) |
|---|---|
| 대상 시청자 | 고등학생~학부 1학년 (수식은 알지만 직관은 없음) |
| 길이 | 3~10분 |
| 언어 | 한국어 |
| 톤 | 3Blue1Brown 식 — 결론보다 "왜 그렇게 되는가" |

정말 갈리는 건 **대상 시청자**와 **이미 아는 것**이다.
"미분을 아는 사람 대상인가, 미분을 처음 배우는 사람 대상인가"로
영상이 완전히 달라진다. 이게 불명확하면 한 번 묻는다.

---

## 2. 핵심 한 문장

전체 영상이 전달하는 사실을 **한 문장**으로 쓴다. 여기서
막히면 주제가 너무 크다는 뜻이니 쪼갠다.

```
✗ "선형대수에 대하여"                  ← 주제지 문장이 아님
✗ "행렬식과 고유값과 대각화"            ← 세 편짜리
✓ "행렬식은 그 변환이 넓이를 몇 배로 만드는지를 나타내는 수다"
```

---

## 3. 비트 구조

기본 5단 구조. 주제에 따라 ④를 빼거나 ②를 둘로 늘린다.

```
① 훅        구체적인 질문/현상 하나              10~20s
② 직관      계산 없이 그림으로만 이해시킨다       60~120s
③ 형식화    그 그림에 기호를 붙인다               60~90s
④ 확장      일반화 / 놀라운 따름정리              60~120s
⑤ 여운      더 큰 그림 한 줄                      15~30s
```

**절대 규칙: 그림이 기호보다 먼저 온다.**
정의 → 정리 → 증명 순서는 교과서지 영상이 아니다.

### 각 비트의 조건

- 비트 하나 = 시청자가 얻어가는 사실 하나. 두 개면 쪼갠다.
- 비트마다 **"이 비트가 없으면 뭐가 안 되는가"**에 답할 수
  있어야 한다. 답이 없으면 지운다.
- 한 비트가 120초를 넘으면 쪼갠다.

---

## 4. 내레이션 먼저, 화면은 그다음

순서를 지킨다:

1. 비트마다 **말로 할 내용**을 문장으로 쓴다
2. 그 문장을 소리 내어 읽고 **초를 잰다** (한국어는 분당 300~350자)
3. 그 초에 맞춰 화면에 뭐가 있어야 하는지를 적는다

반대로 하면 "화면은 화려한데 무슨 소린지 모르는" 영상이 나온다.

길이 계산:
```
글자 수 ÷ 5.5 ≈ 초       (한국어, 차분한 설명 톤 기준)
```

## 5. 산출 형식

`templates/storyboard.md`를 복사해서 채운다. 필수 열:

| 열 | 내용 |
|---|---|
| `#` | 비트 번호 |
| 목적 | 이 비트가 전달하는 사실 한 줄 |
| 화면 | 무엇이 보이고 무엇이 움직이나 |
| 길이 | 초 |
| 내레이션 | 실제로 읽을 문장 (자막 원본) |
| 씬 | 대응되는 Manim Scene 클래스 이름 |
| 템플릿 | 어느 템플릿에서 시작할지 |

**씬/템플릿 열이 채워져야 `manim-video`가 바로 받아쓸 수 있다.**
매핑:

| 화면 유형 | 템플릿 |
|---|---|
| 수식을 항별로 해설 | `formula_walkthrough.py` |
| 수식 A → B 변형 | `transform_anagram.py` |
| 함수 그래프·접선·적분 | `graph_plot.py` |
| 벡터장·선형변환 | `vector_field.py` |
| ODE·물리 궤적·3D | `ode_trajectory.py` |
| 그 외 | `scene_base.py` |

## 6. 수식 이미지 → LaTeX

교과서·논문 스크린샷을 주면 LaTeX로 받아쓴다.
(원본 워크플로우의 Mathpix 자리를 대신한다.)

받아쓸 때 **항을 나눠서** 쓴다. `manim-video`가 그대로
`MathTex(...)` 인자로 넘길 수 있어야 한다.

```python
# 이미지: dx/dt = σ(y − x)
MathTex(r"\frac{dx}{dt}", "=", r"\sigma", "(", "y", "-", "x", ")")
```

통짜 문자열로 주면 색칠도 변형 애니메이션도 안 된다.

## 7. 검토 체크리스트

스토리보드를 넘기기 전에:

```
□ 핵심 한 문장이 쓰여 있다
□ 모든 비트에 "없으면 뭐가 안 되는지"의 답이 있다
□ 그림이 기호보다 먼저 나온다
□ 내레이션이 실제 문장으로 쓰여 있다 (요약 아님)
□ 길이 합계가 목표 길이의 ±20% 안이다
□ 씬 이름과 템플릿이 지정돼 있다
□ 한 화면에 수식이 3개 이상인 비트가 없다
□ 5초 넘게 정적인 비트가 없다
```
