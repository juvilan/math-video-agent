# 의도 카드

> 프로젝트 루트의 `.mv/intent.md` 에 둔다.
> **한 번 정하면 다음 영상에도 그대로 쓴다.** 매 영상마다 취향을
> 처음부터 설득하지 않기 위한 문서다.
>
> Claude는 영상을 만들기 전에 이 파일을 먼저 읽는다. 없으면
> 만들면서 채운다.

---

## 1. 정체성

- **채널/시리즈**: <예: 고등학교 수학 개념 시리즈>
- **주 시청자**: <예: 고1~고2, 개념은 배웠지만 왜 그런지는 모름>
- **한 편의 목적**: <이해시킨다 / 흥미를 붙인다 / 시험 대비>

## 2. 톤

| 축 | 선택 | 비고 |
|---|---|---|
| 차분함 ↔ 경쾌함 | 차분 3 / 5 | 숫자가 클수록 경쾌 |
| 설명 ↔ 발견 | 발견 4 / 5 | "왜 그런가"를 같이 찾아가는 쪽 |
| 엄밀 ↔ 직관 | 직관 4 / 5 | 증명보다 그림 |
| 말수 | 적게 | 화면이 말하게 |

## 3. 화면

- **밀도**: 여백 많이 / 보통 / 촘촘히
- **한 화면 최대 요소 수**: <예: 3>
- **수식 노출**: 최소 (그림 먼저, 기호는 필요할 때만) / 보통 / 적극
- **색 성향**: <예: 파랑 계열 + 노랑 강조. 붉은색은 오답 느낌이라 피함>
- **배경**: `#0f0f14` (기본) / <다른 값>

```
MV_TEXT_SCALE=1.0     글자 크기 배율
```

## 4. 속도

- **기본 배속**: `MV_PACE=1.0`
  (1.0 기준. 1.2면 20% 느리게 — 내레이션을 얹을 거면 올린다)
- **한 비트 길이**: <예: 40~60초>
- **영상 총 길이**: <예: 4~6분>

## 5. 자막

- **표시**: 핵심 구절만 / 내레이션 전문 / 없음
- **한 줄 최대**: <예: 22자>
- **위치**: 하단 고정

## 6. 효과음

- **정도**: 없음 / 최소 (씬당 1개) / 보통 (씬당 2~3개)
- **쓰는 순간**: <예: 결론 확정에만 chime. 등장음은 안 씀>

## 7. 하지 말 것 ← 여기가 절반이다

무엇을 원하는지보다 **무엇이 싫은지**가 더 잘 전달된다.
한 번이라도 "이건 아닌데"가 나오면 여기 적는다.

```
- 예: 캐릭터·이모지 금지
- 예: 통통 튀는 바운스 애니메이션 금지
- 예: 정의부터 시작하지 않기
- 예: 화면 회전은 3D일 때만
- 예: "여러분" 같은 호칭 금지
```
