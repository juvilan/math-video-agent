# 3Blue1Brown 연출 문법

"왜 저 영상은 이해가 되는가"를 규칙으로 환원한 것. 예쁘게 만드는
법이 아니라 **틀리게 만들지 않는 법**이다.

---

## 1. 색은 문법이다

| 규칙 | |
|---|---|
| 변수 하나 = 색 하나 | `x`가 파랑이면 수식·그래프·라벨·화살표 전부 파랑 |
| 동시에 3~4색 | 넘으면 시청자가 추적을 포기한다 |
| 흰색은 "아직 의미 없음" | 강조할 때만 색을 준다 |
| 배경은 순검정 아님 | `#0f0f14` 같은 아주 어두운 회색이 눈이 덜 아프다 |

```python
PALETTE = {
    "x": BLUE_B,        # 첫 번째 변수
    "y": YELLOW,        # 두 번째
    "z": RED_C,         # 세 번째
    "accent": TEAL_A,   # 결론·강조
    "muted": GREY_B,    # 배경 정보
}
```

색을 바꾸는 순간이 곧 "이제 여기를 보세요"라는 신호다. 아무 데나
칠하면 신호가 죽는다.

---

## 2. 타이밍

- **새 객체가 나타나면 최소 0.5초는 아무것도 안 한다.** 눈이
  따라올 시간.
- 수식 한 줄 읽는 데 사람은 2~4초 걸린다. `Write` 뒤 `wait(1.5)` 이상.
- 연속 동작은 `lag_ratio=0.1~0.3`으로 살짝 어긋나게. 동시에
  터지면 뭘 봐야 할지 모른다.
- 한 씬에서 `run_time`이 전부 1초면 리듬이 없다. 0.5 / 1 / 3초를
  섞는다.

### rate_func 선택표

| 상황 | rate_func |
|---|---|
| 객체 등장·퇴장 | `smooth` (기본) |
| 수식 A → B 변형 | `smooth` |
| **시간이 흐르는 궤적 (ODE, 물리)** | `linear` |
| **카메라 회전·팬** | `linear` 또는 `ease_in_out_sine` |
| 슬라이더로 파라미터 훑기 | `linear` |
| 강조 후 원복 | `there_and_back` |

시간축을 표현하는 것에 `smooth`를 쓰면 "끝날 때쯤 시간이
느려지는" 물리적으로 틀린 그림이 된다. 이게 가장 흔한 실수다.

---

## 3. 카메라

- **3D는 반드시 움직여야 한다.** 고정된 3D는 2D처럼 보인다.
  `begin_ambient_camera_rotation(rate=0.04~0.08)` — 이보다 빠르면
  멀미난다.
- 줌은 목적이 있을 때만. "디테일을 보여주려고" 외의 줌은 산만하다.
- 카메라 이동 중에는 다른 애니메이션을 최소화한다. 둘 다 움직이면
  아무것도 안 보인다.

---

## 4. 구도

- 중요한 것은 화면 중앙 또는 좌측 2/3. 우측은 수식·라벨 자리.
- 수식은 `to_edge(UP)`, 그림은 그 아래 — 를 씬 내내 유지한다.
  씬마다 위치가 바뀌면 시청자가 매번 다시 찾는다.
- 화면 밖으로 나가는 요소가 없는지 **스틸 렌더로 눈으로 확인**한다.
  코드만 봐서는 모른다.

---

## 5. 서사

한 씬 = 한 문장. 그 문장을 주석으로 씬 맨 위에 쓴다.

```python
class WhyDeterminantIsArea(Scene):
    """행렬식은 단위정사각형이 변환 후 갖는 넓이다."""
```

이 주석이 안 써지면 씬이 두 가지를 하고 있는 것이다. 쪼갠다.

### 비트 구조 (3~10분 영상)
```
① 훅        구체적인 질문/현상 하나          10~20s
② 직관      계산 없이 그림으로만              60~120s
③ 형식화    그림에 기호를 붙인다              60~90s
④ 확장      일반화 / 놀라운 따름정리          60~120s
⑤ 여운      더 큰 그림 한 줄                  15~30s
```

"정의 → 정리 → 증명" 순서로 가면 교과서지 영상이 아니다.
**항상 그림이 기호보다 먼저 온다.**

---

## 6. 하지 말 것

- 한 화면에 수식 3개 이상
- 설명 없이 지나가는 기호
- 5초 넘게 정지해 있는 화면 (내레이션이 있어도 뭔가는 미묘하게 움직여야)
- 의미 없는 회전·바운스
- 자막으로 내레이션 전문을 그대로 깔기 (핵심 구절만)
