# /mv-revise

요청: **$ARGUMENTS**

제작자가 짧게 말한 걸 구체적 변경으로 옮긴다. 아래 사전에 있는
말이면 **되묻지 말고 바로 적용**한다. 없으면 무엇을 바꿀 계획인지
한 줄로 말하고 진행한다.

## 코드를 안 고치고 되는 것 — 먼저 이걸 본다

```bash
MV_PACE=1.25       전체 속도 (play 의 run_time 과 wait 에 곱해진다)
MV_TEXT_SCALE=1.1  글자 크기
MV_SFX_DIR=...     효과음 위치
MV_LANG=en         언어
```

| 말 | 값 |
|---|---|
| "조금 더 천천히" | `MV_PACE=1.15` |
| "많이 느리게" | `MV_PACE=1.4` |
| "좀 빠르게" | `MV_PACE=0.85` |
| "글씨 키워" | `MV_TEXT_SCALE=1.15` |
| "자막 작게" | `MV_TEXT_SCALE=0.9` |

## 코드를 고쳐야 하는 것

| 말 | 조치 |
|---|---|
| "여백 더" / "답답해" | 요소 `scale(0.85)`, 한 화면 요소 수 줄이기, `buff` 키우기 |
| "허전해" | 요소를 키우거나 보조 라벨 추가. 요소를 늘리기 전에 키우는 걸 먼저 |
| "이 색 말고" | `PALETTE` 교체 → **전 씬 재렌더** (색은 씬을 넘나든다) |
| "자막 줄여" | 내레이션은 두고 자막만 핵심 구절로 |
| "자막 빼줘" | `say()` → `wait()`. 길이는 유지 |
| "효과음 줄여" | `sfx` 호출 삭제. 씬당 1개까지 |
| "3번 비트 빼자" | 씬 삭제 → 총 길이 재계산 → **앞뒤 씬 연결** 확인 |
| "순서 바꿔" | 씬 순서 변경 → `join` 순서도 같이 |
| "구도가 아니야" | **G2로 되돌아간다.** `mv.py sketch` 로 스틸만 고쳐 다시 확인받는다 |
| "설명이 부족해" | 비트 추가는 기획 변경이다. 확인받고 진행 |

## 절차

1. 요청이 **어느 층위**인지 판단한다
   - 노브(`MV_*`) → 재렌더만
   - 코드 → 해당 씬만 수정
   - 구도·비유 → G2 복귀, 스틸부터
   - 비트 구성 → G1 복귀, 확인 필요
2. 바꾼 뒤 `mv.py layout` → `still` → `preview` 순으로 확인
3. **색·속도처럼 씬을 넘나드는 변경은 전 씬을 다시 렌더**한다.
   한 씬만 고치면 이어붙였을 때 그 씬만 튄다
4. `.mv/decisions.md` 에 한 줄 남긴다 — 무엇을 왜 바꿨는지
5. 다음 영상에도 적용될 취향이면 **`.mv/intent.md` 로 올린다.**
   특히 "이건 아닌데"는 **하지 말 것** 목록에 넣는다

## 하지 말 것

- 요청 하나에 여러 개를 같이 바꾸기 — 뭐가 효과였는지 모르게 된다
- 색·속도를 한 씬만 고치고 끝내기
- 기록 없이 넘어가기 — 같은 지적을 다음 영상에서 또 받는다
